# 360 Education Business Analytics Platform

## 📌 Project Overview

This Power BI project presents a **360 Education Business Analytics Platform** with an **Executive Overview Dashboard**. The dashboard is designed to bring together education-business data and provide an interactive view of key performance indicators and business metrics.

The Power BI model includes entities covering **admissions, branches, calls, courses, fees, leads, marketing, placements, students, employees, revenue measures, student measures, lead measures, placement measures, call measures, marketing measures, and date information**.

## 🛠️ Tool Used

- Microsoft Power BI
- Power Query / Data Transformation
- DAX Measures
- Power BI Data Modeling
- Interactive Dashboard Visualizations

## 📊 Dashboard

The report contains an **Executive Overview Dashboard** under the title:

**360 EDUCATION BUSINESS ANALYTICS PLATFORM**

The dashboard uses cards and interactive visuals to present business metrics, including revenue-related measures. The report also contains branch-level filtering

## 🧩 Data Model

The Power BI model contains multiple business areas, including:

- Admissions
- Branches
- Calls
- Courses
- Fees
- Leads
- Marketing
- Placements
- Students
- Employees
- Date Table
- Revenue Measures
- Student Measures
- Lead Measures
- Placement Measures
- Call Measures
- Marketing Measures

This structure supports analysis across different education-business functions.

## 🔄 Project Workflow

1. Data integration into Power BI
2. Data transformation and preparation
3. Data modeling and relationships
4. Creation of DAX measures
5. KPI and metric development
6. Interactive dashboard design
7. Branch and business-level analysis
8. Executive-level reporting

## 🎯 Objective

The objective of the project is to provide an executive-level analytical view of education-business operations and enable users to explore important metrics through an interactive Power BI dashboard.
