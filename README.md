# Data Analytics Project Using Power BI

## 📌 Project Overview

This project is a data analytics and visualization project developed using Microsoft Power BI. It focuses on transforming raw data into meaningful insights through interactive dashboards and visualizations.

## 🛠️ Tool Used

- Microsoft Power BI

## 🔄 Project Workflow

1. Data Import
2. Data Cleaning and Transformation
3. Data Modeling
4. Data Analysis
5. DAX Measures
6. Data Visualization
7. Interactive Dashboard Creation
8. Insights Generation

## 📊 Dashboard

The Power BI dashboard provides interactive visualizations that help users understand important trends, patterns, and key performance indicators from the dataset.

## 🎯 Objective

The main objective of this project is to convert raw data into an interactive and easy-to-understand dashboard that supports data-driven analysis and decision-making.
